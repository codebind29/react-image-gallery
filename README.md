# 📸 React Image Gallery

A responsive and modern image gallery built with React.js, Axios, Tailwind CSS and the Picsum Photos API.

## ✨ Features

- 📷 Fetches images from Picsum Photos API
- 🔄 Dynamic image rendering
- 📄 Pagination
- 🌙 Dark and Light mode
- 💾 Saves theme preference using LocalStorage
- ⏳ Loading state
- ⚠️ Error handling
- 📱 Responsive design
- 🔗 Opens image source in a new tab
- 👤 Displays photographer name
- 🎨 Modern and clean UI

## 🛠️ Tech Stack

- React.js
- JavaScript
- Axios
- Tailwind CSS
- Vite
- Picsum Photos API
